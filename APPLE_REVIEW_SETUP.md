# Apple Review Demo Account Setup Guide

## Overview
This app now supports email/password authentication hidden behind a secret gesture, allowing Apple reviewers to sign in without phone verification.

## Step 1: Create Demo Account in Firebase Console

### Option A: Using Firebase Console (Recommended)
1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Select your project
3. Navigate to **Authentication** → **Users** tab
4. Click **Add user**
5. Enter:
   - **Email**: `applereview@linkupbu.com` (or your preferred email)
   - **Password**: Create a strong password (e.g., `AppleReview2025!`)
   - **User ID**: Auto-generated by Firebase
6. Click **Add user**

### Option B: Using Flutter App (Alternative)
1. Run the app in debug mode
2. Tap the logo 5 times to reveal email/password fields
3. Try signing up with the demo email (if sign-up is enabled)

## Step 2: Add Demo Email to Test Accounts List

### Update Firestore Config
1. Go to Firebase Console → **Firestore Database**
2. Navigate to the `config` collection
3. Find or create the `test_accounts` document
4. Add your demo email to the `emails` array:

```json
{

    "michael@geml.co",

}
```

## Step 3: Complete Demo Account Profile

### Option A: Manually via Firestore Console
1. Go to Firestore Database → `users` collection
2. Find the user document with your demo account's UID
3. Update the document with complete profile data:

```json
{
  "id": "<user-uid>",
  "email": "applereview@linkupbu.com",
  "username": "applereview",
  "displayName": "Apple Reviewer",
  "photoUrl": null,
  "bio": "Demo account for App Store review",
  "classYear": "2025",
  "location": "Boston University",
  "gender": "Prefer not to say",
  "interests": ["Sports", "Music", "Events"],
  "hasCreatedProfile": true,
  "isEmailVerified": true,
  "authProvider": "email",
  "isOnline": false,
  "createdAt": "<current-timestamp>"
}
```

### Option B: Using the App
1. Sign in with the demo account
2. Complete the profile setup flow normally
3. This ensures the account follows the same setup process as real users

## Step 4: Update App Store Connect

When submitting for review, add this to **App Review Information**:

### Demo Account Credentials
```
Email: applereview@linkupbu.com
Password: [your-password]

How to Access:
Tap the LinkUp BU logo 5 times quickly to reveal the email/password login fields below the Google and Apple sign-in buttons.
```

### Sign-In and Security Notes
```
This demo account provides access to the production environment with real user data. The email/password login is hidden from regular users and only accessible via the secret gesture to maintain a clean UI while providing review access.
```

## Security Considerations

### Production Environment
- Demo account accesses the **real production environment**
- Apple reviewers will see actual user posts and data
- This is intentional and follows best practices (Apple prefers reviewing the real app)

### Monitoring (Optional)
If you want to monitor the demo account during review:
- Check Firestore for activity from the demo account UID
- Review Analytics for demo account sessions
- You can delete any test posts created by the reviewer after approval

### Post-Approval Cleanup (Optional)
After app approval, you can:
- Keep the account active for future reviews
- Delete the account if desired
- Remove from test_accounts list (will prevent login via BU email validation)

## Troubleshooting

### "Access restricted to Boston University students"
- Ensure demo email is added to `config/test_accounts` in Firestore
- Check the `_isBUEmail()` function in `auth_service.dart`

### Email/password fields not appearing
- Ensure you're tapping the logo (not the title text)
- Tap 5 times within 2 seconds
- Look for "App Review login enabled" snackbar

### Login fails with "user-not-found"
- Verify account was created in Firebase Authentication
- Check email spelling matches exactly

### Profile setup required after login
- This is normal if you haven't pre-populated the Firestore user document
- Either complete profile manually in Firestore or via the app
